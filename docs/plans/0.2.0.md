# 0.2.0 planning

Draft planning follows the 0.1.7 release; this is not a release checklist or
authorization to bump versions or publish artifacts now.

## Agreed direction

- Keep 0.1.7 saving explicit, with private crash recovery.
- Consider optional source-file autosave in 0.2.0. Define conflict, deletion,
  recovery, Save As and external-edit behavior before implementation; default
  behavior and opt-in settings need review.
- Build on 0.1.7's tabs, note links, file watching and local image support.
- Remote images stay blocked by default. A future per-image “Load image from
  example.com” action may allow that image for the current session only, with
  no document-wide permission or background preloading. This is separate from
  0.1.7 local-image support.

## Scope to choose after 0.1.7

Prioritize Zettelkasten note workflows and decide which of backlinks, note
search, tags and missing-note creation belongs in this release. Treat image
imports (paste/drop), SVG and image editing controls as separate candidates.

Before implementation, agree the smallest useful set, write acceptance tests
and define migration/compatibility behavior for any persisted configuration.
Do not turn every candidate into a release requirement.
