# Textgate v0.1.2

This milestone completes priority 2 (large-document performance) and includes
the save-integrity work completed after v0.1.1. Priority 3—zoom and accessibility,
including optional hybrid relative line numbers—is next.

- Limit Live styling to visible text; preserve selection-based markup reveal.
- Move word counts and full outlines to background jobs; reuse outline buttons.
- Avoid whole-document string comparisons for dirty tracking, including undo.
- Add manual Source-preview refresh for documents of 1,000,000 characters or more.
- Save through a flushed temporary file and confirm before replacing external edits.
- Explain busy file operations when another action or close is requested.

Performance measurements and their limits are in `docs/performance.md`.
Tables over 50,000 characters remain editable source in Live mode. File watching,
crash recovery, and autosave are not included. Native smoke tests remain on the
release checklist; passing CI is not a substitute for those checks.

## Downloads

- Linux x86-64: AppImage, DEB, or RPM. Make the AppImage executable before running.
- macOS: choose `aarch64.dmg` for Apple Silicon or `x64.dmg` for Intel.
- Windows x64: choose the EXE installer or MSI.

Builds are unsigned; macOS builds are not notarized. OS security checks may warn
or block launching them. The tag workflow creates a draft release for package
review; this milestone does not publish the first official release automatically.
