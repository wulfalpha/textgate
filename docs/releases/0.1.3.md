# Textgate v0.1.3

The first official release of Textgate, a lightweight desktop Markdown editor
built with Rust, Tauri 2, CodeMirror 6 and comrak.

**Your Markdown file is the document.** Textgate never re-serializes it: only
your own edits are saved, and line endings (LF or CRLF) and a UTF-8 byte order
mark are kept exactly as they were.

## Highlights

- **Live mode** styles Markdown in place and shows the markup where you are
  editing. **Source mode** shows the plain text beside a GitHub-flavored preview
  rendered by comrak (tables, task lists, footnotes, alerts).
- **Vim bindings** and **hybrid relative line numbers** (View menu), in both modes.
- **Safe saving:** saves go through a temporary file that replaces the original
  only once fully written. If the file changed or was deleted outside Textgate,
  you are asked before anything is overwritten. Files opened through symbolic
  links or linked folders save to the linked file and keep the link.
- **Large documents** stay responsive: Live styling covers only what is on
  screen, and the outline and word count update in the background.
- **Accessibility:** window zoom (Ctrl/Cmd `=` `-` `0`), F6 to move between the
  outline, editor and preview, text colours that meet WCAG AA contrast, and
  right-to-left lines (Arabic, Hebrew) in the editor and preview.
- **Themes:** Default, a **System** theme that follows your OS dark mode, and
  your own CSS files.
- **Keyboard:** Ctrl/Cmd+Shift+X checks or unchecks tasks; Ctrl/Cmd+B and I for
  bold and italic. Help → Keyboard shortcuts lists them all.

## New since v0.1.2

- View → Zoom In / Zoom Out / Actual Size, remembered on each device.
- System theme, keyboard task toggle, right-to-left text support.
- F6 / Shift+F6 pane cycling; the preview can be scrolled from the keyboard.
- Higher contrast for line numbers, muted text and code-block numbers in the
  light theme; screen-reader text for the unsaved marker and task symbols.

## Downloads

| Platform | File |
| --- | --- |
| Linux x86-64 | `.AppImage`, `.deb` (Debian, Ubuntu) or `.rpm` (Fedora, openSUSE) |
| macOS Apple Silicon | `aarch64.dmg` |
| macOS Intel | `x64.dmg` |
| Windows x64 | `x64-setup.exe` or `x64_en-US.msi` |

The `.app.tar.gz` files are for a future auto-updater; you do not need them.

**These builds are unsigned.**

- **macOS:** after copying Textgate to Applications, the first launch may be
  blocked. Right-click Textgate and choose **Open**, or run
  `xattr -cr /Applications/Textgate.app` once.
- **Windows:** SmartScreen may warn about an unknown publisher. Choose
  **More info → Run anyway**.
- **Linux AppImage:** `chmod +x Textgate_0.1.3_amd64.AppImage`, then run it.

## Known limitations

- No file watching, autosave or crash recovery yet. Opening files from the
  command line or file manager is not supported yet.
- Tables over 50,000 characters stay as editable source in Live mode.
- Large documents (1,000,000 characters or more) update the Source preview when
  you choose Refresh.

Report problems at https://github.com/wulfalpha/textgate/issues.
