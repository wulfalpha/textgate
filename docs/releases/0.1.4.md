# Textgate v0.1.4 (draft)

Stabilization work toward v0.1.5. These notes describe unreleased changes;
version fields are set to 0.1.4; hosted builds and native package validation
are still pending.

## Markdown remains authoritative

- Saving an unedited UTF-8 file now preserves mixed line endings byte for byte,
  along with its BOM, whitespace and final-newline presence. Previously, mixed
  endings were silently standardized to the most frequent style on save.
- Edits retain existing line endings; new breaks use the file's predominant
  style. Undo/redo restore line-ending metadata as well as text.
- Edit → Normalize line endings… explicitly standardizes to LF, CRLF or CR.
  This is undoable and triggers unsaved-change protection, even without text
  changes. Save writes the requested normalization to disk.
- Save snapshots include line-ending metadata, so continued editing during a
  save cannot change which version is marked as saved.

See the README for the preservation policy and the CR/LF adjacency edge case.
Native package smoke tests remain pending in the release checklist.


## Release validation

- Release builds run JavaScript and Rust tests on each build runner before
  packaging. Both Mac architectures are packaged; Intel remains a cross-build.
- CI verifies matching npm, Cargo and Tauri versions, including lockfiles.
  Tag builds require the exact matching tag, `v0.1.4`.
- The Live-preview test setup now explicitly completes visible syntax parsing,
  avoiding timing-dependent assertions under build load.
- The comrak HTML snapshot is checked out with LF on every platform, matching
  the renderer's output when Rust tests run on Windows.
- A [package testing guide](../testing-0.1.4.md) and byte-exact fixture generator
  cover preservation, normalization and native regressions.

Builds remain unsigned. Use the platform installation guidance in the README.
Windows and Linux package smoke tests will be performed on the user's machines
once draft downloads are available; the release is not yet ready to publish.
