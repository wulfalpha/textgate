# Textgate v0.1.4 (unreleased)

## Command-line and file-manager opening

- Open `textgate notes.md`, quoted paths, relative paths, or local `file://` URLs.
- Use `--` before a filename beginning with a dash; `--help` and `--version`
  print information without starting a window.
- Open a missing file as an empty named document; create it only on Save.
- Forward a second invocation to the existing window using the caller's directory.
- Queue incoming opens during file operations and preserve discard prompts.
- Register `.md` and `.markdown` associations, with native Finder open-event handling.
- Reject multiple paths rather than silently choosing one in the single-document UI.

The native grant applies only to the supplied path. Existing atomic saves and
external-change detection apply to files opened from the CLI as well as dialogs.
An edit made while a discard confirmation is open now triggers another check.

## macOS packaging

Mac bundles explicitly use ad-hoc signatures, verified by the release workflow.
They remain unnotarized. For a trusted download copied into Applications, the
interim installation command is:

```sh
xattr -dr com.apple.quarantine "/Applications/Textgate.app"
```

Manual re-signing is not part of the installation steps. The user reported an M1
download/build test on 2026-10-31; the revision and packaged-download behavior
were not specified. Fresh M1/M4 packaged-download testing after only quarantine
removal remains unconfirmed; old v0.1.3 downloads are unchanged.

A [fresh CI artifact test on M4](../macos-validation.md) confirmed a valid ad-hoc
signature and successful launch after targeted quarantine removal without
re-signing. Gatekeeper assessment still rejects the unnotarized app. This test
used a temporary copy with synthetic quarantine, not a browser installation.

## Validation and limits

Checks now runs JavaScript and Rust tests, formatting and Clippy on Linux, macOS,
and Windows. All three passed at `8535bca` in the
[2026-10-30 Checks run](https://github.com/wulfalpha/textgate/actions/runs/41004392254).
The Windows renderer-fixture checkout issue is fixed by pinning those fixtures
to LF; this does not change the line endings of user documents.
Package smoke tests and fresh Mac signature/install checks remain pending; see
the [release checklist](../release-checklist.md) and [0.1.5 plan](../roadmap.md).
The CLI does not add a PATH entry, support stdin/`--wait`, accept multiple paths,
or open at a line/column. Linux single-instance forwarding uses the desktop's
session D-Bus. No new release has been tagged or published by this change.
