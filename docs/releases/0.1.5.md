# Textgate v0.1.5: the spell check update

This release adds spell checking, fixes the Vim block cursor and Vim's file
commands, and bundles the document and code fonts so Textgate looks the same on
every platform.

## Spell checking

- **View → Check spelling** underlines misspelled words using the system spell
  checker, with suggestions on right-click. It is on by default and remembered
  on each device.
- Code spans, code blocks, URLs, raw HTML and YAML front matter are not checked.
- **macOS:** uses the system dictionaries. Textgate now opts in to WebKit's
  check-while-typing setting, which is off for apps by default.
- **Linux:** WebKitGTK's spell checker is enabled at startup, with languages taken
  from `LANGUAGE`, `LC_ALL`, `LC_MESSAGES` and `LANG` (falling back to US
  English). Install a Hunspell dictionary for your language, such as
  `hunspell-en_us` on Arch or `hunspell-en-us` on Debian/Ubuntu.
- The editor now has keyboard focus at launch, so checking starts without a
  click and you can type straight away.

**Known issue: Windows.** The setting is present, but no words are underlined on
Windows. The cause has not been identified yet; the rest of the app is not
affected.

**Known issue: Linux AppImage.** The AppImage finds spelling dictionaries only
on Debian- and Ubuntu-based systems. On Arch, Fedora, openSUSE and other
distributions nothing is underlined, because the spelling library bundled from
Ubuntu looks for its Hunspell plugin at Debian's fixed path. Use the `.rpm` on
Fedora or openSUSE, or a source build. A relocatable build is planned for
0.1.6.

## Vim

- The block cursor stays full height while a command is pending (after `d`, `c`,
  `y`, a count or a register) and in Replace mode, instead of shrinking to half
  or a fifth of its height. The status bar now shows `Vim REPLACE`.
- At a line end or on an empty line the block is about a character wide, rather
  than a sliver of the proportional font's space.
- File commands now work, through the same save checks as the menus:

  | Command | Action |
  | --- | --- |
  | `:w`, `:w!` | Save |
  | `:sav` | Save As (choose a new file) |
  | `:wq`, `:x` | Save, then close; stays open if the save is cancelled or fails |
  | `:q`, `:qa` | Close; refuses with `E37: No write since last change` if there are unsaved changes |
  | `:q!`, `:qa!` | Close without saving |

  File names after `:w` and `:wq` are not supported; use `:sav`.
- The `:` and `/` prompt uses the editor's font, aligned and padded, and the
  block cursor is outlined in the accent colour while the prompt has focus.

## Fonts

Textgate now bundles **iA Writer Quattro S** for document text (Live mode,
preview and tables) and **iA Writer Mono S** for code, Source mode and the Vim
prompt. Before, the intended fonts were usually missing and each platform fell
back to a different system font. Menus and the toolbar keep the system font.
The fonts are unmodified and licensed under the SIL Open Font License 1.1
(see `web/fonts/LICENSE.md`); CSS themes can still override them.

## Development

`npm run tauri dev` no longer crashes on Windows with `EBUSY` while Cargo builds:
the Vite dev server now ignores the `target` folder.

## Downloads and installation

| Platform | Download |
| --- | --- |
| Linux x86-64 | `.AppImage`, `.deb` or `.rpm` |
| macOS Apple Silicon | `aarch64.dmg` |
| macOS Intel | `x64.dmg` |
| Windows x64 | `x64-setup.exe` or `x64_en-US.msi` |

Installation is unchanged from 0.1.4. On macOS, copy Textgate from the DMG to
Applications; packages are ad-hoc signed but not notarized, so if macOS blocks a
trusted download, use **System Settings → Privacy & Security → Open Anyway**.
Windows installers remain unsigned; if SmartScreen warns, choose **More info →
Run anyway**. For the Linux AppImage:

```sh
chmod +x Textgate_0.1.5_amd64.AppImage
./Textgate_0.1.5_amd64.AppImage
```

## Validation

- Hosted Checks passed on Linux, macOS and Windows for the 0.1.5 branch,
  including the platform-specific spell-checking code.
- Local checks: 99 JavaScript and 24 Rust/CLI tests, formatting and the frontend
  build. New tests cover the spell-check exclusions and setting, the Vim cursor
  corrections and every Vim file command, including E37 and cancelled saves.
- User-verified in development builds: spell checking on macOS (M4) and Arch
  Linux; the Vim cursor, prompt, `:wq` and fonts on macOS; a clean Windows 11
  build with the spelling setting present. The remaining Vim commands are
  covered by automated tests and listed for package testing.
- Package-level checks are tracked in the [release checklist](../release-checklist.md).

## Limits

Spell checking does not work on Windows yet, or in the AppImage outside
Debian/Ubuntu (see above). Vim's `:w` and `:wq`
do not accept file names. Textgate still edits one document per window; the file
browser and tabs are planned for 0.1.6, and links, file watching, autosave and
crash recovery for 0.1.7.
