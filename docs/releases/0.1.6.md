# Textgate v0.1.6: tabs and a file browser

Draft: Linux and macOS checks passed; Windows shortcut retesting is pending.

## Platform status

Tabs, the file browser and opening several files were tested by hand on Linux
and macOS (Apple Silicon). Windows MSI testing confirmed tab switching, close
and quit dialogs, file creation/rename/trash, and CLI/Explorer multi-file
opening. Explorer Open With required adding Textgate manually. Ctrl+S and
Ctrl+W failed in the first package; the shortcut fix awaits a rebuilt-package
retest. Spell checking still does not work on Windows.

## Tabs

- Each open document has its own tab, with its own undo history, cursor and
  scroll position. Live/Source mode, Vim, line numbers and spell checking apply
  to every tab.
- **New** opens an empty tab and **Open** accepts several files at once. A file
  that is already open, even through a symbolic link or linked folder, is shown
  in its existing tab instead of opening twice.
- Closing a tab with unsaved changes asks **Save / Don't Save / Cancel**.
  Quitting lists every tab with unsaved changes. Closing the last tab leaves an
  empty Untitled one.
- Shortcuts: Ctrl/Cmd+W closes a tab; Ctrl+Tab / Ctrl+Shift+Tab and
  Ctrl+PageDown / PageUp switch tabs (Cmd+Shift+] / [ on macOS); Ctrl/Cmd+1–8
  go to a tab and 9 to the last. The tab bar works with the keyboard and is part
  of the F6 cycle.
- Vim: `gt` / `gT` (with counts), `:tabnext`, `:tabprevious`, `:tabnew` and
  `:tabclose`; `:q` closes the current tab and `:qa` closes all of them,
  refusing with E37 while any tab has unsaved changes.

## File browser

- **File → Open Folder…** (or `textgate ~/notes`) makes a folder the workspace.
  The sidebar's **Files** view lists its folders, Markdown and text files, in
  natural order, loading folders as they open. The workspace and its open
  folders are reopened at the next launch.
- Click a file to open it in a tab while keeping focus in the list, so F2 and
  Delete / Cmd+Backspace act on it; press Enter to open it and start typing. The
  current file is highlighted;
  open and unsaved files are marked.
- Right-click, the menu key or Shift+F10: **New File…**, **New Folder…**,
  **Rename…** (F2), **Move to Trash…** (Delete) and **Show in File Manager**.
  Open tabs follow renames; a trashed file's tab keeps its text. Nothing is
  replaced or deleted outright.
- The sidebar switches between **Files** and **Outline** (View → Outline is now
  **View → Sidebar**), and its width can be dragged.
- Access stays explicit: Textgate reaches only the chosen folder, checked after
  resolving symbolic links.

## Opening files

- `textgate a.md b.md c.md` opens each file in its own tab, and a running
  Textgate receives them as new tabs. `--` now covers every later argument.
- Selecting several Markdown files in Finder or a Linux file manager and choosing
  Open With → Textgate opens all of them.

## Fixes

- **Linux AppImage spell checking** now works on every distribution with Hunspell
  dictionaries, not only Debian and Ubuntu. The AppImage bundles a relocatable
  build of the spelling library with its Hunspell plugin, and the release build
  checks that it finds a dictionary.

## Limits

Tabs are not restored after a restart (planned with crash recovery in 0.1.7).
The file browser does not watch for outside changes yet (0.1.7); it refreshes
when the window regains focus.
Save As onto a file that is open in another tab is refused; close that tab
first. Spell checking still does not work on Windows.
