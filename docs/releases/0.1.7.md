# Textgate v0.1.7: recovery, note links and local images

Recovery and restored tabs, outside-change detection, links between notes and
local images in Preview and Live mode.

## Recovery and restored tabs

- Private recovery checkpoints preserve unsaved buffers, including BOM and line
  endings, tab order, the active tab and primary selections from the checkpoint.
- After an interrupted session, recovered text returns as unsaved. Named notes
  retain their old disk baseline, so Save still detects outside edits/deletion.
- After a normal quit, named tabs reopen from current disk contents. Quit
  Without Saving discards draft text; discarded Untitled notes do not return.
- Checkpoints do not autosave over Markdown files. They are local plaintext,
  written atomically with private permissions, limited to 512 tabs/64 MiB.
  Failed writes keep the previous checkpoint; corrupt or unsupported data is
  kept untouched with a warning. Edits after the last checkpoint can be lost.
- Undo history and scroll position are not restored after restarting.

## Outside file changes

- Clean tabs reload outside edits. Dirty/recovered tabs keep their editor text
  and show a warning; Reload from Disk asks before discarding edits.
- Deleted or externally renamed files keep their tab contents. Save asks before
  recreating the old path; external renames are not followed automatically.
- Native notifications refresh open files and visible workspace folders, with
  focus checks and a periodic fallback. Save conflict checks remain authoritative.
- Reload preserves BOM/line endings and the primary selection, starts a fresh
  undo history, and updates inactive tabs without stealing focus.

## Links between notes

- Relative Markdown links and `[[note]]` / `[[note|Label]]` wiki links open notes
  in tabs and reuse tabs that are already open. Heading fragments use the native
  renderer's anchor rules, including duplicate and Unicode headings.
- Click links in Preview; use Ctrl/Cmd+click or Ctrl/Cmd+Enter on inline/wiki
  links in the editor. Reference-style Markdown links work in Preview.
- Wiki links without extensions use `.md`, checking the current note's folder
  first and then the workspace root. There is no recursive basename search.
- Linked files must be in the open workspace or already granted through Open.
  Missing links report an error and do not create files.

## Local images

- PNG, JPEG, GIF and WebP images render in Source Preview and, for inline
  images, Live mode. Moving into a Live image exposes its unchanged Markdown.
- Paths are relative to the saved note, or the workspace for an Untitled note.
  Use Open Folder to grant access to images in that workspace. Existing native
  file grants are retained; ungranted outside paths and symlink escapes are refused.
- Filenames with spaces work with standard Markdown syntax:

  ```md
  ![Screenshot](<images/My screenshot.png>)
  ```

  Encoding spaces as `%20` also works; keep macOS screenshot spacing intact.
- Images are limited to 8 MiB each. Preview limits image count/data and Live
  widgets are viewport-bounded. Unavailable or undecodable images show accessible
  placeholders with alt text. SVG and remote/embedded image URLs are not loaded.
- Reference-style images render in Source Preview and remain source in Live mode.
  Use Preview → Refresh to reread changed image bytes; image files are not yet
  watched independently. Image import/insertion controls are separate work.

## Editing fixes and preferences

- Blank bullet, numbered and task lists can be started from the toolbar, with
  the caret after the new marker ready for typing.
- View → Show line endings displays unobtrusive LF/CRLF/CR markers without
  changing the file or Preview. It is off by default and remembered.
- Vim bindings are off by default and remember both enabled and disabled states.
- macOS startup disables smart-dash substitution for Textgate, preserving typed
  `---` table separators without changing system preferences or existing text.

## Packages and verification status

The candidate source is `0c8260ffb816c814dc6fbcd330ee1cce93eca1ce` (merged PR #7).
Its hosted Checks passed; combined local validation passed 150 frontend tests,
60 Rust unit tests, 2 CLI tests, the frontend build, formatting, Clippy and
version consistency checks. Manual M4 checks and user builds covered recovery,
discard behavior, file-change handling, links and local image display.

The [candidate package build](https://github.com/wulfalpha/textgate/actions/runs/42341619888)
of this source passed on all four platforms, and its nine packages were
inspected and checksummed (see docs/release-checklist.md).

Expected downloads: Apple Silicon and Intel Mac `.dmg`/app archives, Windows
x64 MSI/NSIS installers, and Linux x86-64 AppImage/DEB/RPM packages. Mac packages
are ad-hoc signed, not notarized; Windows installers are unsigned. Follow the
README installation guidance for packages from this repository.

The downloaded candidate packages were tested by hand on Apple Silicon macOS
(DMG), Linux (AppImage) and Windows: they install and launch, and links and
local images work. The DEB, RPM and Intel Mac packages were built and inspected
but not tested by hand. Windows spelling remains a known limitation.

## Next release

Saving remains explicit in 0.1.7. Source-file autosave is planned for 0.2.1.
Remote images also remain blocked; a future per-image, session-only permission
action is planned separately. No automatic updater is included.
