# Textgate
## Goals
Create a Markdown editor with the following properties:
1. WYSIWYG editor
2. keyboard friendly
3. github flavored markdown
4. cross-platform
5. vim keybindings
6. sidebar with outline and file explorer tabs
7. live preview
8. Markdown Tables

## Ideas
- Use Tauri for the cross-platform GUI
- keep ui simple
- app should remain light weight.
